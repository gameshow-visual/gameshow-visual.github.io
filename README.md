# 🎮 GameShow & Visual

## 🇧🇷 Português

### 📌 Sobre o Projeto
Este projeto é voltado para o desenvolvimento de **jogos interativos acessíveis**, destinados a **todas as pessoas**, incluindo **pessoas com deficiência (PCD)**.

O objetivo é promover inclusão, diversão e interação, garantindo que qualquer usuário possa participar da experiência de forma igualitária.

### 🌐 Formas de Interação
A interação com os jogos pode ocorrer de duas formas:
- **Presencialmente**
- **Por meio de streaming**, permitindo a participação remota dos usuários
